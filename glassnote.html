One-time Google Cloud setup (2 minutes)
  1. Open Google Cloud Console → APIs & Services → Library and enable Google Drive API.
  2. Under Credentials → Create Credentials → OAuth client ID, choose Web application.
  3. Add the URL below to both Authorized JavaScript origins (origin only) and Authorized redirect URIs, then paste the Client ID above.

How to host a temporary share link (1 command)
  1. On your PC, run npm run collab (starts a temporary local + Wi-Fi relay on port 5174).
  2. To share over the internet, run cloudflared tunnel --url http://localhost:5174 and paste the https://….trycloudflare.com URL above — or deploy collab-worker/ free on Cloudflare Workers.
